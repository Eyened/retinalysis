## Purpose

Retinalysis inference brings released retinal models into an image-analysis workflow. It combines model loading, the expected preprocessing and ensemble prediction, so research code can work with a consistent interface.

<div className="facts">
<div><h3>Inputs</h3><p>Model releases and image datasets, supplied as tables or preprocessed inputs.</p></div>
<div><h3>Outputs</h3><p>Predictions, ensemble aggregates and inspectable model intermediates.</p></div>
</div>

## Capabilities

- **Shared preprocessing:** retain the geometry and input preparation expected by a model release.
- **Ensemble outputs:** work with aggregated predictions or inspect member-level outputs.
- **Dataset workflows:** apply releases to image collections rather than only individual tensors.
- **Runtime settings:** adjust supported inference options, such as augmentation or windowed processing, for the selected release.

## Output geometry and limitations

High-level spatial outputs use the package’s canonical preprocessed geometry, normally 1024 × 1024 for fundus workflows. They are not automatically mapped back to the original photograph. Lower-level prediction outputs can use model-specific geometry, so follow the release documentation when interpreting coordinates.

This is an execution library. Validation performance and suitable populations belong to the individual model and evaluation study. Consult the release documentation for preprocessing and hardware requirements.
